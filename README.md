# 나만의 프롬프트 관리 프로그램 (B2-A)

터미널 기반으로 자주 사용하는 AI 프롬프트(텍스트 생성, 이미지 생성, 페르소나 등)를 효율적으로 저장, 검색, 관리할 수 있는 파이썬 콘솔 애플리케이션입니다.

---

## 📌 주요 기능
1. **프롬프트 추가**: 제목, 내용, 카테고리를 선택하여 새로운 프롬프트 등록
2. **프롬프트 목록**: 저장된 전체 프롬프트를 번호, 카테고리, 즐겨찾기 여부와 함께 조회
3. **카테고리별 조회**: 카테고리를 선택하여 해당 그룹의 프롬프트만 필터링 출력
4. **프롬프트 검색**: 제목 및 내용 전체 대상 키워드 검색
5. **프롬프트 상세 보기**: 선택한 프롬프트의 카테고리, 즐겨찾기 여부, 전체 내용 확인
6. **즐겨찾기 관리**: 특정 프롬프트의 즐겨찾기 여부(True/False) 토글
7. **즐겨찾기 목록**: 즐겨찾기 등록된 프롬프트 모아보기

---

- **Library**: External Library None (Python Built-in Standard Library만 사용)
